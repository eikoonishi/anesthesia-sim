# 麻酔管理シミュレーション

LLM(Claude)を用いた周術期アナフィラキシー対応のチャット型シミュレーション。

## シナリオ
45歳女性・腹腔鏡下胆嚢摘出術。全静脈麻酔で導入後、術前抗生剤(セファゾリン)投与によりアナフィラキシーが発症。学習者は麻酔科医として診断・治療・搬送までを行う。

## 構成

| ファイル | 役割 |
|----------|------|
| `index.html` | 麻酔導入Q1〜Q4 + 挿管ナレーション + アラーム発生 |
| `chat.html` | 急変対応フェーズ(自由テキスト/音声入力でAIと対話) |

## 機能
- 5種の生体モニタ波形(ECG / NIBP / SpO₂プレチ / EtCO₂カプノグラム / BIS脳波)
- SpO₂連動ピッチの心拍音
- Anthropic Claude API(Haiku 4.5)を使った文脈的AI応答(APIキー未設定でも内蔵ルールベースで動作)
- 音声入力(Web Speech API、Chrome/Edge)
- 「対応終了」ボタンで必須対応の達成状況をチェック

## 注意
本シミュレーションは教育目的であり、実臨床判断の根拠としないこと。
参考文献は使用前に必ず最新版をご確認ください。

## 利用環境
- ブラウザ:Chrome / Edge / Safari(音声入力は Chrome / Edge 推奨)
- HTTPS 必須(マイク・Claude API のため)
